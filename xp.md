# Verified repository experience

- A reset from a stale feature branch is recoverable when the pre-reset HEAD is recorded as an annotated tag before creating the new baseline branch.
- Binary product assets should be audited by hash before and after repository cleanup; visual identity files are not regenerated as part of an architecture reset.
- Historical architecture material can remain useful for research only when it is physically separated under an explicitly obsolete archive and excluded from active source-of-truth paths.

- A connected/manifold fleece can still look like separate balls or melted dough.
  V003's actual clay loop caught a crown flap that was less obvious in front
  color, and a 160-iteration relaxation erased small cloud rhythm. Check at
  least front, oblique clay and rear after field/smoothing changes; technical
  connectivity is not a visual acceptance test.
