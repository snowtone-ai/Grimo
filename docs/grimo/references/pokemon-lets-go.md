Source channel: **aika**
Playlist: **「【ピカブイ】ピカチュウとの触れ合い集」** (around 10 videos).
Use Pikachu mainly as a biped reference and Eevee as a quadruped reference when body topology matters.

## Video 1

URL: https://www.youtube.com/watch?v=0KSZwNZ5m1E&list=PLyNPy006ABoGutSw0Tj29MkGIXS-5tH-k&index=2

### 0:09–0:18 — nose touch → sneeze
User observation: nose touched → pre-sneeze face → sneeze → head shake → normal.

Grimo principle: a touch reaction can be a short causal story rather than a single clip. Preserve the chain:
`local contact acknowledgement → anticipation → primary reaction → follow-through → settle → normal`.

### 0:30–0:45 — high five
User observation: cute; the Pokémon initiates the high-five request.

Grimo principle: include self-initiated invitations such as “touch me / interact with me,” not only passive responses.

### 0:30–0:34 / 1:16–1:20 / 2:42–2:45 — emotional symbols
User observation: ♪ / ♡ / ☆ effects appear with the reaction.

Grimo principle: VFX should act as **emotional punctuation**, not constant decoration and not a mask for weak body motion.

### 1:18–1:27 — feeding
User observation: food is eaten in roughly three stages instead of vanishing instantly.

Grimo principle: consumables should have visible progression such as `whole → bitten → small remainder → gone`, with corresponding mouth/body reaction and short afterglow.

### 2:31–2:35 — head shake
User observation: a cute head-shake micro-motion.

Grimo principle: build a small reusable micro-motion vocabulary (head shake, tiny recoil, ear flick, gaze reset, etc.) that can be composed around larger reactions.

User observation: the Pokémon initiates the event and it connects directly to item acquisition; randomness is preferable.

## Implementation translation

Do not copy Pokémon-specific motion shapes. Translate these references into Grimo’s own body topology and Character Bible. The important transferable elements are causality, anticipation, self-initiation, staged consumption, micro follow-through, restrained emotional VFX, and settle/afterglow.
