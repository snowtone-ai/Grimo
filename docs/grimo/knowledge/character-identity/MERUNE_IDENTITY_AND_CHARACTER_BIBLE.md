## 2. Identityの破壊禁止境界

- **守る:** 顔の幼さ、目の大きさ／位置／透明感、丸い頬・鼻口の短い奥行き、耳の輪郭と厚み、前髪、豊かな胸毛、胸の器官の位置と形、体側モチーフ、尾の巻きと根元、4肢の支持、クリーム・ラベンダー・ピンク・ゴールドの相互関係。
- **動的でも守る:** 瞬き後に眼球が収まる眼窩、閉口／発声後の口角、耳根、胸リブ、尾の巻き。中立姿勢に戻るとCanonicalの顔・シルエットを保つ。
- **Body-onlyでも残す:** 身体に生えた毛・前髪、耳内の層、胸のハープ、身体の旋律・音符・星、尾の金線。これらを「装飾だから不要」と除去しない。
- **本体から除けるもの:** 背景や身体から浮遊した独立VFX／音符／光粒。Canonical原本は修正せず、3D入力用派生素材でだけ区別する。
- **禁止:** 尾を背負い物・平面コイル・浮遊輪にすること、胸の器官を脱着アクセサリへ格下げすること、耳を薄板にすること、瞳を平板な貼付けにすること、全身バウンスだけで生命感を偽装すること。

## 3. Personality / 演技文法 [DIR・Human未承認]

**仮説: 「世界の小さな響きを聞き取り、気に入ると、自分の旋律をそっと返したくなる子」。** 単なる音楽再生マスコットでも、いつも歌う陽気な猫でもない。好奇心と穏やかな自己表現を両立し、相手の気配に耳を傾けてから反応する。Jill（エネルギーと共有欲）、Pino（自由な実験・探索）、Shushu（落ち着いた自律）と**動機／テンポ／身体の演技**で区別する。

- **気づき:** 視線と片耳の向きが先に変わり、もう片耳や前髪がわずかに従う。実際の入力・自発的な視線移動以外から「聞こえた音」を捏造しない。
- **受容:** 触れられた側の耳・頬・胴がまず答える。その後に瞳・顔・上体、最後に尾が控えめに遅れる。小さな接触を毎回全身の曲芸にしない。
- **嬉しさ:** 目の輝きと口元、胸の穏やかな収縮／拡張、少し遅れた尾のカーブで表現。ハープの光や音なしでも読み取れる。
- **集中・待つ:** 片耳を向けたまま静かに保持できる。休む時間は故障ではなく性格表現。
- **誘い:** 視線を送り、頭・胸または接地を保った自由な前脚を小さく示し、ユーザーの返答をWAIT。無応答なら自分で落ち着く。寂しさ・罪悪感を演出しない。
- **境界:** 苦手な接触は小さな耳の後退／向きの変化→穏やかな身引き→自然な回復。嫌悪や罰ゲームにはしない。

本節は**Humanが性格として承認する前の実装方向案**。設定の文字だけで感情・意思が通じたと主張しない。

## 4. Character-specific control envelope [DIR]

- 顔：眼球・視線、上下瞼と瞬き、頬・口角・小鼻周辺、開口／閉口を独立または局所変形で制御。
- 耳：左右独立の回旋／傾斜と必要な内部構造の追従。左右同時往復の単純ループは避ける。
- 胸共鳴器官：本体に位置固定された器官として首／胸の皮膚・毛と整合。繊細なリブや弦は必要な可動性だけ持つ。振動・光・音は**補助**であり必須ではない。
- 四肢・体幹：4足支持・荷重移動・伏せ・真の後躯支持の座位。前脚を持ち上げる際は残る足／胴の支持が成立すること。
- 尾：根元の連結と巻きシルエットを保ちつつ、遅延・停止・追従。渦全体を硬い輪として回転するだけにしない。
- 模様：体側音符と金線は表面に追従し、Rigで滑落・反転・左右複写しない。
- 声・音符・VFXは**オプション**。無音・減音設定・低性能環境でも同じ意思が身体だけで伝わること。

## 5. Visual / experience acceptance

1. **Identity Human:** 原本と正面・3/4・側面の静止画像を並べ、目の愛らしさ、顔の奥行き、耳内部、胸器官、尾、体型が揃い「メルネに見える」とHumanが認める。1枚絵から未規定の背面は整合性に基づき提案し別承認。
2. **Expression Human:** 瞬き・視線・開口・耳・尾の表現で形が破綻せず、中立へ戻る。Canonicalの開いた笑顔を「必ず閉口中立」に書き換えない。
3. **Experience Human:** 静かな15–30秒、触れ合い、誘い→WAIT、割込み、反復、数分間のふれあいで音／VFXなしでも生き物らしい。
4. **Runtime:** 保存GLBの再読込、PlayCanvas、スマホで可愛さ／接触／表示・操作安定性を維持。技術PASSとHuman GOを混同しない。
