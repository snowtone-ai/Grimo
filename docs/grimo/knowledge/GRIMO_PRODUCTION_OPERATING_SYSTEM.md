# Grimo production principles

Grimo exists to make smartphone task management feel warmer through living companion characters. Cuteness, appeal, comfort, attachment, interaction quality, and believable life outrank technical purity.

Use current explicit user decisions and approved/canonical references over historical implementation material. Keep current execution state in Git and the relevant production-state file; historical evidence is useful provenance, not instruction.

No production method is sacred. Tools, model choice, workflow order, intermediate architecture, testing method, and implementation strategy may change as better evidence arrives. Use the smallest meaningful implementation and validation for the risk at hand. Avoid unrelated work and preserve local user assets.

Human perceptual acceptance remains necessary for visible identity, cuteness, naturalness, and companion quality.
