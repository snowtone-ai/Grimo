# Grimo character production architecture

Characters must be believable through the views and motions the product actually exposes. The front companion presentation has especially high visual importance, but visible off-axis surfaces and motion-critical parts need enough spatial structure, attachment, and deformation readiness to avoid obvious collapse.

Visible quality outranks technical purity. Hidden structure is functional; modular meshes and hybrid rendering techniques are acceptable when the visible character remains coherent and responsive. Whole-finished-character image warps are not a substitute for a living spatial character.

Full-spatial 3D with view-weighted polish is the current working baseline, not permanent implementation law. Tooling, topology, rigging, rendering, and validation can change when a better approach serves the companion experience.
