# 標準外観 v001 — 3D構造契約

正本は `shushu-Identity-canonical.png`。赤線は装備範囲の指定のみで造形しない。この会話では赤線添付を再取得できず、既存Canonical原本を直接確認した。

- 頭頂側の主花と右耳前の主花は各5花弁。前者を少し大きく高く置き、別々の傾きで重ねる。中央は直径約1/3の3つの小さな重なり片であり、独立した大輪にしない。花冠化しない。
- 花弁は先端切れ込み、淡い中心から濃桃色の縁、浅い反りを持つ閉じた薄殻。裏面に5萼片、コンパクトな花床と短い花柄を置き、頭表面近くの共通取付け部へ接続。厚みは主花0.0015H、小意匠0.0008H。自然の多数の蕊は控えめな黄色中心に簡略化する。
- 葉はCanonicalで読める上左・上右・中央下・右・下の5領域。葉身を反らせ中央脈を高くし、葉柄で同じ取付け部につなぐ。花の後ろに葉、さらに後ろに柄・萼。見えない奥行き・背面・接点は推定補完であり、2D原画の観察事実と混同しない。
- 花/葉/裏側は独立12 Meshを1個のGLB rootにまとめる。頭部ローカルAnchorの子として追従。承認済み頭・耳を変形しない。装備ON/OFF・交換・disposeを独立制御する。
- 肉球は左右後足裏の既存UV上に各「大中央1＋上側小3」。座位の実表面上で楕円を定義してUVへ戻す。新しい浮遊Mesh・前足への推測追加はない。既存skin/morphと同じ面が動く。

花弁/萼/花柄と葉身/主脈/葉柄の区別は実植物に基づく。大小・色・5葉の配置・小意匠・柔らかい質感はCanonical優先のデフォルメ。[出典と適用範囲](SOURCES.md)。
