# 花飾り v002 — 3D構造契約

Authorityは[Canonical](../../../../../assets/grimo/source/shushu/shushu-Identity-canonical.png)。主花2輪の中心・半径・傾き・5花弁の外形と切れ込み、小さい中央3lobes、5葉の位置をv001から保持する。中央意匠を独立した第3大輪へ拡張しない。身体・頭・耳は変更しない。

- **実物構造：** 桜の5花弁、先端切れ込み、裏の萼・花床・短い柄、葉身・中央脈・葉柄を参照。一次資料と取得限界は[v001 SOURCES](../standard-appearance-v001/SOURCES.md)に保存済み。
- **Canonical優先のデフォルメ：** 淡い中央から濃桃色の縁へ移る色、控えめな黄色中心、2輪の大小と重なりを優先。多数の長い雄蕊や実物の薄さをそのまま再現しない。
- **花弁の断面：** 表裏の曲面を丸い縁で閉じる。中央付近に最大約0.014Hの厚みを持ち、先端・縁へ連続的に薄くする。均一な板厚や全体を膨らませた球面を使わない。極座標の微小うねりは中心へ収束させ、中央の尖った反射を除く。
- **表裏と接続：** 表面は頭の前外方へ、裏面は頭へ向く。小さな花床・萼の内側に短い花柄を収める。葉は既存5位置に厚みと中央稜を持つ曲面、裏の葉柄から同じ隠れた取付け領域へ接続する。前面に柄を露出させない。
- **質感：** 不透明な柔らかいサテン。roughness 0.43、coat 0.12 / coat roughness 0.45、sheen 0.10。透過・金属・強い鏡面を追加しない。GLBはKHR_materials_clearcoat / sheenを使用し、製品のPlayCanvas 2.22.2で実描画を確認する。
- **装備契約：** 独立GLB/Blend、12 semantic Mesh、1 item root。既存v001 installerと同じHead-local Anchor・切替・解放を再利用。v004製品loaderはv002を通常ON。承認済み後足PNGはv001の同一bytesを使用する。

正面原画にない厚み・裏面・接続は制作補完であり、Canonicalに新しい装飾があるとは主張しない。追加の揺れMotionはこの変更に含まない。最終の柔らかさ・上質感・Identityとの一致はHuman PENDING。
