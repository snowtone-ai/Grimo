## A. Behavior North Star

**「何を感じているか」を説明する前に、どこへ注意を向け、何を自分で選び、何を終えずに残したかが身体から分かること。**

Jillは自分の嬉しさに相手の参加場所を作る。Pinoは自分の行為と起きた結果を見比べる。Shushuは自分で選んだ心地よい姿勢・感触を保ちながら相手を迎える。同じ笑顔や静止があっても、それまでの身体の選択と、その後に何を続けるかが違う。

演技の成否は、可愛さ・癒やし・愛着を保って、この違いが30秒から3–5分の体験で読めるかにある。大量の動き、常時の閉眼、音・VFX、説明台詞を理解の必須条件にしない。本文の短い台詞は演技意図の比喩であり、新しい発話やUIではない。

## B. Common Behavioral Semantics

### B1. 共通Interfaceの意味契約（コード・rig非依存）

| 意味単位 | 受け渡す情報 / 判断 | 守ること |
|---|---|---|
| Input / semantic touch | 開始・移動・継続・解放・cancel、実際のzone/side/接触位置、利用可能なgesture・方向・速度・継続、同じ接触か新接触か | 端末が取得できない圧力を「強く押した」と推定しない。取得不能な情報はunknownとして扱う |
| Attention | 今の対象、その根拠（有効なtouch、存在するprop、自分の身体、対話方向）、保持中の関心、注視を解く意思 | 接触の検知と、主注意を移す選択は別。無入力時は自己行為を対象にできるが、存在しない物を発見しない |
| Emotion | 快/戸惑い/期待/安心/軽い不快等の現在の混ざり方・強さ・余韻と、その原因 | 喜びを残しながら驚ける。全身を一つの感情presetへ瞬間切替しない |
| Motivation | 今したいこと、満たされたか、続けるか、保留・終了するか | 各個体の理由はC–F。数値好感度・隠し親密度・Relationship XPは作らない（Product §17のA） |
| Decision | 受容、接触を求める、続行、共有への招待、保留、境界、解放、休息のうち今の理由に合う選択 | 最後の入力を必ず全身で演じる仕組みにしない。小さい受容と行動しない選択にも、分かる根拠を持たせる |
| Performance intent | 何を相手に伝えるか、最初に意味を担う部位、参加する部位、動かさず残す支持/接点、終了の意味 | 共通のhappy clipや固定face→body順は返さない。個体別演技がこの意味を実現する |
| WAIT / offer | 誘いの目的、見せている対象/関わり、現在も応答可能か、受け取れる返答、取り下げた事実 | 必須正解gestureや成功回数を作らない。期限切れ後の入力は現状態の新入力として受け取る |
| Satisfaction / afterglow | 何が十分になったか、残す感情・姿勢・注意、終える意図と継続する意図 | 動作終了≠感情終了。ユーザーが応じなくても別の形で満足・休息できる |
| Recovery / interruption | 現在の接点・支持・pose・affect、保留中の意図、有効なoffer、propの保持/受領段階 | 強制Neutralや古い入力の連続再生を挟まない。ACKと大きな行為の切替を分離 |
| History / repetition | 直近のzone/side/gesture、受容/境界とその解放、誘いの結果、やりかけ/完了、似た表現の直近使用 | 文脈が同じなら小さな反応へ。意味のない左右反転や機嫌の乱数化で差を稼がない。永続的な関係スコアを加えない |
| Product facts | Foodの食べ方/好き度、現在の所持・使用可否、Wear装着先と装着成立等、製品側で確定した事実 | 演技は物の消失を見て消費を推測しない。感情/好き嫌いが在庫・所有・報酬規則を勝手に変えない |

### B2. 選択・保持・終わり方

共通なのは次の質問であり、固定のanimation pipelineではない。

1. **今の身体で入力をどう受け取れるか。** 有効なtouchには局所ACK。支持・口元・保持物を壊す大きな反応は避け、今可能な顔/局所の変化で受理を読ませる。
2. **何を続ける価値があるか。** 各個体の主動機、接触への快、不快のhint、進行中の受け取りを照合。眠気があれば眠さを持った受容が可能。
3. **何を変えれば意思が伝わるか。** 必要な注意・表情・身体だけを選ぶ。新しい入力ごとに新しい全身phraseを積まない。
4. **今の意図はどう終わるか。** 満足、取り下げ、境界が尊重された回復、関心の移行を区別する。終わった意図だけを手放し、温かさや未完の関心は残せる。

identity/safetyには、転倒・滑り・口や保持物の破綻を防ぐことを含めて解釈する。local ACKを返すために支持を壊す必要はない。各個体に同じ身体の優先順を機械的に流用しない。
### B3. WAITと境界の意味を混ぜない

**WAIT：** 意図を見せる → 応答可能な形で保つ → 応答を受け取る、または自分で申し出を解く。狙った対象以外へのtouchにも、その場所のACKを返す。触られた場所を無視してoffer成功へ飛ばさず、その接触を受け取る交流へredirectしてよい。無応答で大きくなり続ける催促はない。

**境界：** 過密さ・集中・十分さ等の理由がある → 小さいhint → 続くならmild refusal → 必要なwithdrawal → 刺激が解ければrecovery。穏やかな反復は受容のままでもよい。boundary後の普通の快い接触は受け取れるが、同じ過密入力なら境界を保つ。ユーザーの謝罪や贈物を回復条件にしない。

### B4. 引き継ぎと反復抑制

- 入力解放時はその瞬間のcommit量から接触を解き、動作の先頭/末尾へ飛ばない。反対側への新touchは旧接点の解放と新区域のACKを区別する。
- 近い入力が続く間は、既に受け取っている快/集中を更新し、毎回「初めて気付く顔」を再生しない。持続するtouchを大量のtapとして扱わない。
- 似た演技の再使用を減らすだけでなく、誘いが終われば静かな満足、探究が終われば休息、という**選択の変化**を優先する。休息を故障として新動作で埋めない。
- セッションの直近履歴は演技の連続性のために使う。非表示中に寂しさや空腹を蓄積しない。復帰時は古い接触/offerを有効扱いせず、現在の製品状態と整合して落ち着いた状態から再開する。

## D. Jill Performance Direction

**画面で読む核：自分の楽しい動きの途中に、相手へ開いた静かな余地を作り、返事が届いたことを身体で喜ぶ。**

| Grammar | 具体的な選択と演技 |
|---|---|
| Motivation | 自分の嬉しさを相手も含む出来事にしたい。返事の大きさや正確さを試さない |
| Attention | 自分の伸び/小さな遊びから対話方向へ顔を向ける。接触が返れば、触点に気付いた顔が相手への嬉しさへ変わる |
| Decision | 私的な上半身の伸びを、相手に開かれた姿勢へ変えて誘う。返事がなければ自分の伸びを心地よく終えられる |
| Performance Lead | 自発的な気持ちは胸/上半身が起点、顔がその宛先を示す。touchのACKは接触箇所が先で、翼の動きで代用しない |
| Action | 足を置いたまま胸を少し起こし、前肢を低く外へほどく。翼は上半身の開きに応じて控えめに参加。返事を受けると一度前肢が身へ寄り、嬉しさが胸から外へ広がる |
| Intentional Stillness | WAITでは胸の上昇を終え、前肢を低い位置に保ち、足/尾根元を静かにする。翼を往復させて空白を埋めない |
| Satisfaction | 返事が届いたと分かる顔と胸の喜びがあれば十分。前肢/翼が休む方向へ戻り、次の催促を始めない |
| Afterglow | 胸は落ち着いても、返事を受けた相手への柔らかな関心が残る。口を最大に開いた笑顔を保持し続けない |
| Interruption | 喜び中の新touchはその部位で受ける。胸の快は残せるが、広げかけた翼/前肢をcontactへぶつけない。残りの大きい演技は省ける |
| Variation | 小さな返事なら顔/胸だけで喜べる。共有直後は私的な休息へ。無応答の後に触られたら現在のJillが歓迎し、旧offerの成功演技を遅れて再生しない |

**支持と身体：** 胸を起こすときも重心は現在の足/承認された支持域内。重い尾は胴の動きに根付いて従い、反動で本体を飛ばす棒ではない。翼・葉・花は主意図の従属表現。角様付属を耳として折る、飛行、翼で物を握る能力を前提にしない。

**感情の幅：** 嬉しさの漏れる小さな胸と、待てる下半身の対比を使う。眠さには胸の伸びを途中でやめて休む選択、不満には胸を少し守りながら接触側を避ける選択を持つ。常時はしゃいでいる表情には固定しない。

**テンポと強弱：** 自分の意欲が立ち上がる区間と、相手の参加を待てる静かな区間を対比する。返事にはまとまった嬉しさで応じ、その後はきちんと休む。活発さを一定周期の上下動にしない。

## E. Pino Performance Direction

**画面で読む核：自分で変えた箇所を見て、一度止まり、違うやり方を試す。結果に納得すると、相手に見せ続けず手放せる。**

| Grammar | 具体的な選択と演技 |
|---|---|
| Motivation | 身近な接触や動きの違いを自分で試したい。成功の拍手ではなく、変わった結果が面白い |
| Attention | 自分の前肢の先と接点に目/顔が向く。動かす前肢から、接した/離れた結果へ視線の焦点が移る。頭touch時は触点側で気付ける |
| Decision | 例として、内寄りの前肢の先をそっと合わせ、離して、今度は触れる手前で止めてみる。継続したいときだけ再試行。結果が分かれば終える |
| Performance Lead | 対象が既に関心内なら前肢の小さな試みが始まり、顔が結果を確かめる。新しい刺激なら顔の気付きが先でもよい。毎回eyes-firstに固定しない |
| Action | 一方の前肢を静かに残し、もう一方を寄せる/離すことで、原因と結果を見えるように分ける。顔が少し近づいても、全身を前へ転がさない |
| Intentional Stillness | 結果を見る時は試している前肢も止める。反対前肢と下半身が比較の基準として残る。尾を同時に振って手元の意味を隠さない |
| Satisfaction | 接点/隙間を確かめて小さく表情がほどけ、両前肢の緊張を解く。毎回ユーザーを見て褒め待ちにしない |
| Afterglow | 面白かった手元への関心または満足が残る。相手が加わった場合は、その触れられた領域と相手に短い親しさを向けられる |
| Interruption | 頭/頬を触られたら局所でACKし、試していた前肢を安全な位置で保留。手元への入力なら接点を検討し直す。どちらも先頭から実験を再演しない |
| Variation | 納得した試みは再び初発見にしない。直近で同じ遊びを終えたら休む/触れ合いを選ぶ。触点側、保留していた前肢、眠気で再開か終了を選ぶ |

**支持と身体：** 前肢を使う例は、足等で既に安定して支えられている時の候補。Canonicalの丸さ・短さのまま届く範囲で行い、指を器用に分離したり手首を人間のように回したりしない。厚い尾の追従は主身体の変化に従い、tailを支柱にすることを前提にしない。両前肢の接触到達・顔からの視認・独立支持はU。

**感情の幅：** 予想との差には目/口の小さな戸惑いがあり、試し直すか「これでいい」と終えられる。日々自分の手を初めて発見する乳児にはしない。既知の身体でも遊び方を変えて楽しむ、幼い探究として提案する。好きな撫でへ自分から関心を移すことも人格に含む。

**テンポと強弱：** 小さい試みと、結果を見るはっきりした停止を分ける。試し方を変えると動き出しの意欲も変わるが、等間隔の往復にはしない。Jillの「返事が来たから開く」リズムと区別し、結果が分かれば余計な再試行を省く。

## F. Shushu Performance Direction

**画面で読む核：まず自分に合う重みの置き方があり、その安定を崩さず、相手が関われる面を開く。満足したら自分でその時間を閉じる。**

| Grammar | 具体的な選択と演技 |
|---|---|
| Motivation | 自分が心地よいと選んだ感触・姿勢を味わい、共有できれば相手を迎えたい |
| Attention | 片前肢を腹前の届く面へ沿わせる、または既にある花束へ注意を向ける。落ち着いた顔が、その自分の対象から対話方向へ開く |
| Decision | 自分の快を捨てて接客し直さず、安定した胴を残し、顔の向きと前肢の置き方を少し変えて接触/共有の余地を作る |
| Performance Lead | 自分で居心地を整える時は荷重と前肢の置き直しが先、満足が顔へ現れる。touchは触点のACK、共有は対象と相手を結ぶ顔が意味を担う |
| Action | 支持域内で下胴をわずかに落ち着かせ、片前肢を腹前に休める。頭/頬の接触には顔をその側へ開き、不要な前肢の構えを解く。全身を手へ寄せることを代表演技の主眼にしない |
| Intentional Stillness | 自分で選んだ胴/支持位置と、使わない前肢を残す。花束があるなら保持を続け、表情のために手放さない |
| Satisfaction | 喜びの顔が落ち着き、受け取りのために開いていた前肢を楽な位置に休める。「この感じで十分」が終点。境界が不要なら接触を受けたままでもよい |
| Afterglow | 自分の心地よい姿勢に、共有できた温かさが加わる。顔は相手を排除せず、再び手元や自分の落ち着きへ注意を置ける |
| Interruption | 胴/propの安定を保って触点側にACK。新しい快を選ぶなら開く向きを変える。今を選び続ける場合も、小さな顔の評価を省いて無反応にしない |
| Variation | 何を味わっていたか、どの接触が心地よかったか、今十分かによって受容/招待/完了を選ぶ。好みをランダムに反転させない |

**支持と身体：** plushの沈みは、足・腹/腿等の役割が読み分けられる局所の荷重表現。短脚を胴へ潰して高さを稼がない。座位を必要条件にせず、現在の成立する姿勢内で小さく整える。頬へ自分の手が届く、花冠を取って見せる、花束がない所へ出現させる能力は要求しない。

**感情の幅：** 好きな感触には意外にはっきり口元や前肢がゆるむ。驚いた後に味わう方向へ戻ることで感受性を示す。遅いACKや細い目の品定めを、落ち着きの記号にしない。

**テンポと強弱：** 居方を整える行為には小さい終点があり、その後は味わう時間を広く取れる。touchへの受理は明確で、好きなら嬉しさも隠さない。選んだ快を保ち、自分で完了する区切りを重視する。
## G. Representative Scenario Matrix

**G1–G7で全28場面を網羅する。** 「→」は例としての意味の進行であり固定尺/固定演技数ではない。各行に起点、視線/表情、動く部位と残すもの、満足/余韻、支持/接触、入力変更、個体差とユーザー価値を含める。詳細はHの指定scriptで補う。

### G1. 30秒間の無入力

全員、必ず誘う・必ず大きい動作をする義務はない。身体内の行為や休息を注意の対象にし、架空の虫や音を常時発生させない。

胸の伸び・前肢の試み・居方の調整は、人格を検証する代表的な入口である。全idleをこの動きだけで満たす指定でも、新しい常用Signatureの承認でもない。C–Fの動機と現在の状態から、既に十分なら何も始めず休む選択も保つ。

| 個体 | 理由 → 可視の進行 / 静止・余韻 | 支持・接点 | 入力が来たら | 違い / 感じてほしいこと |

### H2. Shushu — 自分の快を保って、撫でを迎える

**対象：G1,G2,G4,G5。** H1と同じ穏やかなL頬touchで比較する。外部propsなし。片前肢を腹前の届く場所に休め、胴の重みが安定した状態。自分を抱きしめるために腕を伸長しない。

1. **自分で選んだ居方：** 支持内で重みを落ち着け、腹前の前肢も休む。手元へ向いていた目と口元が、心地よさを示す。顔を隠すほど頭を下げない。
2. **こちらにも気付く：** L頬touchをL側の顔/頭で受ける。目は接触への注意を示し、口元は温かいまま。胴と下半身は、先に選んだ居方を残す。
3. **自分の時間へ迎える：** 顔をL側へ少し開く。構えていた前肢があれば低くほどくが、自分やpropの支持を担う前肢は残す。頬を大きく押し付けるための追加前傾ではなく、いまの姿勢の中に接触を受け入れる。好きな感触なら目/口がはっきり喜んでよい。
4. **満ち足りる：** 受け取りの構えを終え、前肢を再び楽な場所へ休める。touchが続くなら快い静かな受容、解放されたなら手元や自分の居方へ注意を戻せる。相手への温かさは消さない。
5. **自発的に招く場合：** 心地よかった頬を見せ、顔だけを対話方向へ開く。胴の安定はそのまま。無応答なら顔の招待を解き、手元/居方の満足へ戻る。落胆の下向き顔を挟まない。

**反対側・境界：** Rへ接触が移ればR側でACKし、顔を開き直す。好きな触れ方でも十分なら、開いていた顔を楽な向きへ戻すことが終了hint。過密な入力が続く場合だけ穏やかな回避へ進む。前肢を休めたこと自体を拒否と判定しない。

**他個体との判別：** 接触前からあった自分の姿勢・前肢の居場所が残り、接触後に自分で満足を閉じる。H1と同じleanを小さく再生する案ではない。

**失敗像 / 受容したい感覚：** 小さい表情だけで入力を長く待たせる、顔をそらして冷たく終わるのは失敗。「この子の好きな時間に、こちらも迎えられた」が狙い。

### H3. Jill — 私的な伸びを、共有の余地へ変える

**対象：G1,G4–G6。** 前肢を低く動かしても足等の支持が残る姿勢。玩具、掌への正解tap、空中移動を必要としない。

1. **まず自分が楽しい：** 胸を少し起こし、前肢を低く外へほどく。翼は胸の開きに従う範囲だけ参加する。顔は伸びの心地よさを持つ。下半身と尾根元は支持を保つ。
2. **誰かと一緒にしたくなる：** 顔を対話方向へ向ける。上半身をさらに大きく振る代わりに、伸びを落ち着いた開きへ収める。楽しかった姿勢と、相手に向けた顔の組合せで誘いを見せる。
3. **WAIT：** 胸と前肢を応答可能な位置へ保ち、翼を止める。期待が口元や小さな胸のゆるみに残っても、次の派手な動作を始めない。目は緊迫した凝視にしない。
4. **普通の頭touchが返る：** 頭の局所ACK。相手を受け取った顔と共に、低い前肢が一度身へ寄り、胸から嬉しさがほどける。翼まで参加する必要がなければ使わない。「触られたから伸びが続く」ではなく「返事が届いたことで嬉しさの宛先ができる」。
5. **満足：** 前肢と胸を休ませる。顔は相手への温かさを残すが、同じ招待へ即戻らない。小さな返事で満足できることを見せる。

**無応答分岐：** 段階3から、顔を自分の伸びの感覚へ戻し、胸と前肢を心地よく休める。落胆→入力で救済の物語にしない。非成立の招待でも、その前にあった楽しさが完結する。

**喜び途中の別touch：** 段階4で反対頬を触られたらその側にACKし、広げかけの胸/翼は接点を邪魔しない大きさに収める。嬉しい顔のまま新側に向ける。大喜びをもう一度先頭から足さない。

**他個体との判別：** 原因の中心はユーザーが応じたこと。H4では、ユーザーの参加後にもPinoの目が結果へ戻る。Jillは結果の検分より「返ってきた」相手との関係を締めくくる。

**失敗像 / 受容したい感覚：** 胸を開いて待つだけで訓練の命令待ちに見えるなら、私的な楽しさから招待へ変わった因果が不足。「私の小さな返事で、この子も嬉しくなった」が狙い。

### H4. Pino — 水泡も外部アイテムもない、小さな試み

**対象：G1,G4–G6。** 両前肢を内側へ動かせる安定した支持姿勢での候補。手指の分離、特殊な床、反射や影の仕掛けを使わない。関心対象は実在する自分の前肢と接点だけ。

1. **やってみる：** 一方の前肢を低い胸前に残し、もう一方を寄せ、丸い先端同士を軽く接触させる。目はその接点を追う。肩/胴を両側同時に振って拍手にしない。
2. **結果を見る：** 接したところで動かす側も止まる。顔が少し近づき、口元に小さな「おや」がある。次を急いで反復せず、何を見ているかを見せる。
3. **違いを試す：** 動かした側を少し離し、今度は触れる直前に止める。目は前肢から隙間へ関心を移す。下半身と残した前肢が比較の基準となる。接した/接していないが画面で区別できることが必須。
4. **自分で納得する：** 小さく表情がほどけ、前肢の緊張を解く。面白ければ別の試し方への関心が残り、十分なら休む。必ず相手を見て評価を待つことはしない。
5. **共有を選ぶ場合：** 試していた前肢の先を低く見える位置に残し、動かす側を引いて、接点への空間を開く。対話方向を短く見て招く。前肢への有効なtouchが来たら、そこに小さく反応して目を接点へ戻し、「自分で触れた時と違う」を確かめる。頭touchなら頭の好意として受ける。正しい押し方や報酬条件を作らない。

**頭touchによる中断：** 段階2/3なら、前肢を現在の安全な位置で止め、触点側の頭/顔でACK。口元が嬉しさへほどけても、両前肢を突然投げ出さない。解放後、残った接点/隙間を見て続けるか、納得済みとして休む。入力のために姿勢が変わったなら、同じ結果が残っているふりをせず試みを閉じる。

**無応答：** 提示した前肢を自分の範囲へ戻して続きを選ぶ。ユーザーを無視した誇示や、答えが来るまでの試行ループにしない。完了後の同じ試みを毎回初発見として演じない。

**U / 代替の境界：** 前肢がCanonical比率のまま接触可能か、隙間と目の注意が縦画面で読めるかは未実証。不可なら腕を伸ばさない。同じ「自分が動かす→身体上の接点が変わる→結果を見る」の意味を、実際に届く自分の身体の範囲で再設計し、Humanに戻す。一般的なpaw-waveや水泡で代用して達成扱いにしない。

**失敗像 / 受容したい感覚：** 手を揉む癖、拍手、指示待ち、毎回自分の手を発見する乳児に見えたら失敗。前肢の非対称な役割、試した後の停止、変えた箇所への視線が核心。「私なしでも面白がれる子が、その途中を開いてくれた」が狙い。

### H6. 受領の途中でも同じ相手 — Shushuの一口Food

2. **物と身体が接する：** Foodが口元に届き、受領が成立する。両前肢を自動で持ち上げる儀式はしない。食物の可視状態と受領/消費の製品事実を一致させる。
3. **ここで頬への新touch：** 接触側の顔/まぶた等、口元の受領を壊さない小さい局所ACKを返す。口を瞬間的に笑顔へ切り替えたり、頭を回してFoodを空中に残したりしない。必要な口/保持の動きだけsafe nodeまで継続し、大きな応答はそこから選ぶ。
4. **味を確かめる：** 口の食べる行為が落ち着き、顔の評価が見える。5なら目が少し開く意外な喜びから、口元と前肢の柔らかな満足へ。3の普通の満足、2の苦手評価とは区別する。
5. **味わう余韻と新しい接触：** 胴の重みを落ち着け、Foodを楽しんだ快を残したまま、まだ有効なtouchに顔を開く。途中で解放されたtouchの大きな反応は遅れて再生しない。受領済みなら、割り込みを理由にFoodをもう一度出現・消費させない。

**好き度1は別分岐：** 受領前に顔を丁寧に外して拒否し、Foodは未消費。ユーザーへの冷笑や不在の罰へつなげない。

**他個体との違い：** 同じ受領上の制約の中で、Jillは口の処理後に胸から共有の喜びを開き、Pinoは味の意外さを確かめた納得を残す。制約は共通でも、全員を同じ食後ダンスにはしない。

### J2. Touch：局所の事実を消さない

- **局所ACKの可視候補：** 頬は触点近くのごく小さい受けと接触側の顔の評価、頭は触れた場所へ応じる小さい頭の受けと顔/近側付属の選択的参加。柔らかい形状変化は実際の材料/可動域が許す場合だけ。角・硬い付属を凹ませない。耳や笑顔だけが動き、触れた場所が分からないACKは不足。
- **位置とside：** screen座標ではなく、実際に当たった身体面のzone/sideを保持する。screen-leftを解剖学的Lへ固定しない。中央頭頂はcentralのまま。touchが面を横切れば、旧区域の受けを解きながら新区域のACKへ更新する。
- **動く身体と接点：** 身体が寄る場合も接触位置を実際の面に対応させる。指が止まっていて身体が離れたなら無接触として解き、磁石のように手を追う・zoneを元位置に残す・違う場所を押されたままにすることを避ける。
- **複数の接触：** 受理された接点は別々に扱うが、身体は同時に両方向へ大きくcommitしない。複数入力を採用するかは製品側の入力方針に従う。受理された新接触には可能な局所ACK、主姿勢は支持と既存接触を考慮して一つの整合した選択にする。古いtouchをclip列へ蓄積しない。
- **自分の接触とユーザーtouch：** Pinoの前肢同士の接触は自己行為。ユーザーが触れたことにはしない。入力を受けて前肢が動く場合も、物理的なdrag機能や力センサーを新設せず、局所の受容として表現する。
- **入力が終わる時：** release/cancel/画面離脱で有効な接触は終わる。余韻は残せるが、押されている形・待ち続ける古いoffer・未受理消費を残さない。
