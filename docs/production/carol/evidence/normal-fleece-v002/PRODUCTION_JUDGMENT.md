# Professional production judgment applied to Carol v002

Research date: 2026-09-28. Public primary sources only; no tools, skills, subscriptions or paid assets installed/purchased. These sources inform execution judgment, not Carol's identity authority.

## Sources and concrete application

1. [Thunder Cloud Studio — Character Modeling Workflow](https://thundercloudstudio.artstation.com/blog/mpQLn/character-modeling-workflow-creating-realistic-3d-viking-characters), especially reference breakdown and quick sculpt/blockout. The studio emphasizes establishing the concept's large forms and judging a coherent silhouette before fine detail. **Carol application:** assess normalized Front and Side together; separate face aperture, chest scallops, crown and flank masses. Move the cheek's depth instead of deleting the Front frame. Recess the chest's connecting core so the authored scallops remain visible. Do not use topology counts as evidence of appeal.

2. [Walt Disney Animation Studios — Look Development](https://disneyanimation.com/process/look-development/). The studio describes reference-led shape refinement and layering material ingredients with masks, then iterating the assembled character. **Carol application:** maintain one continuous pigment coordinate space; evaluate pearl base, azure/lilac pigment, upper-surface glaze and contact tint separately. Preserve a restrained material finish that reads with the face; inspect it on the full character and in surface crops. Procedural shading is an authoring implementation, not a runtime equivalence claim.

3. [Julien Kaspar / Blender Studio — Stylized Character Workflow](https://studio.blender.org/training/stylized-character-workflow/). The public course overview identifies character development, sculpting and the later production stages as distinct parts of creating a stylized film character. **Carol application:** deliver an explicit neutral modeling/look candidate with spatial evidence while leaving motion, rigging and runtime gates unasserted. Only the public overview/search excerpts were accessible; no claim is made to have studied subscriber-only lesson contents.

## Reference-specific judgments

- The approved Front and Side remain the comparison authorities. Rear, top and 3Q are spatial checks derived from the same asset.
- Rounded gold accessories may depart from reference outlines under the latest Human exception. They still need physical volume, attachment and readable orientation.
- New fleece/tail shape-key values must be exactly neutral before any appearance comparison. A non-neutral image is not trustworthy fit evidence.
- Eye dark-silhouette dimensions are measured relative to character height, with antialias uncertainty disclosed. Numeric agreement cannot establish likeness, warmth or cuteness.
- One saved `.blend` must produce every delivered native view. Comparison sheets are layout-only crops/scaling/mirroring, never paintovers of defects.
- Human perceptual acceptance remains a separate decision. No arbitrary automated score or technical audit can award it.
