# Obsolete 2D/2.5D archive

This directory contains historical Grimo product and source-pack material from the former PixiJS/layered 2D/2.5D direction.

It is retained only for research and recovery. It is not current architecture, not a production baseline, and must not be used to resurrect the old runtime or asset pipeline. The current direction is Full 3D → Blender → GLB/glTF → PlayCanvas.
