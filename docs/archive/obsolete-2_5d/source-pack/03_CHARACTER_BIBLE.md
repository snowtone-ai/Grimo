# Carol

## Identity
- 幼い羊型グリモ
- 夢雲のような非常に大きい白〜淡青紫の雲毛
- 小さなクリーム色の顔
- 非常に大きい茶〜琥珀系の艶のある瞳
- 茶色の耳と蹄
- 三日月・星モチーフ
- 柔らかい夢・夜空・雲の印象

## Motion signature
- 大きい雲毛全体が柔らかく遅れて追従
- 頭・頬は安心感のある小さな傾き
- 耳は小さく反応
- 足先は重く、身体ほど大きく揺らさない
- 月・星は特殊反応の候補

## Known Touch Map
過去に明示済み:
- GREEN: 頭頂、ほっぺ、耳の付け根
- YELLOW: 胴体の雲毛、背中
- RED: しっぽ周辺、足先
- CYAN: 三日月、星
- GRAY: 瞳、口の内側

注意: 背中として指定された領域はYELLOW。

## Prohibited
- 羊毛を硬い球体集合に見せる
- 軽い紙のような全身揺れ
- 蹄がゴムのように伸びる
- 月/星を常時派手に点滅させる
- 顔より装飾が主役になる

# Jill

## Identity
- 若草色の幼いドラゴン型グリモ
- 丸い頭・胴体
- 大きな緑の星入り瞳
- 淡いクリーム色の腹
- 黄緑〜黄色の翼膜と角
- 頭〜背中に葉のたてがみ/装飾
- 白い小花、クローバー、葉
- 太く曲がる尻尾
- 春・植物・生命力の印象

## Motion signature
- 感情が胸/上体へ出る
- 翼が小さく開閉
- 葉は本体より一拍遅れて揺れる
- 尻尾は根元から重く動き、先端が追従
- 喜び時は胸を起こして少し前のめり

## Prohibited
- 翼を高速で虫のように羽ばたかせる
- 尻尾全体を同時角度で棒のように回す
- 葉を硬いスパイクに見せる
- generic western dragonの骨格へ寄せる
- 葉/花のsecondary motionが本体より先に動く

# Pino

## Identity
- 水色〜青の幼いカワウソ型グリモ
- 白〜クリーム色の顔下部と大きな腹
- 丸くぷにっとした身体
- 短い耳
- 大きな青い艶のある瞳
- 青い肉球
- 太い尾
- 虹色の透明感ある泡 / シャボン玉
- 水しぶき
- 清涼感、水、柔らかさ

## Motion signature
- 胴体は水袋のように柔らかく弾む
- 尻尾は大きく一拍遅れて追従
- 手は物を抱くように内向き
- 嬉しい時は肩と頬が上がる
- 水滴/泡は本体より遅れて動く

## Prohibited
- 水を硬い透明プラスチックにする
- 尻尾を軽い猫尻尾のように高速で振る
- 胴体を中身のない風船のように伸縮させる
- 泡を常時大量発生して反応を隠す
- 腕や足の接地/保持関係を無視する

# Shushu

## Identity
- 白と桜色の幼いパンダ型グリモ
- 丸い白い顔・胴体
- 桜色の耳・腕・脚
- 大きなピンク〜茶系の艶のある瞳
- 花形ハイライト
- 頭に桜の花冠
- 手に花束
- 桜、花びら、蝶
- 柔らかいぬいぐるみのようなシルエット

## Motion signature
- 身体はぬいぐるみのように柔らかく少し遅れて沈む
- 耳は小さく弾む
- 腕は花束を抱えたまま胸元で動く
- 花・花びらは本体より遅れて追従
- 足は重めで接地感を保つ

## Prohibited
- 四肢を細長くする
- 座位の重心を失って浮かせる
- 花束が手から浮く
- 花冠と顔の位置関係を崩す
- plush感を失う硬いパーツ回転
- 目の花形ハイライトを別デザインへ変える

# Cross-character rule

4体は同じruntimeを共有しても、同じ動きにはしない。

- Carol: 雲毛 / 夢 / 安心 / ゆっくり
- Jill: 胸 → 翼 → 尻尾 / 葉の遅れ
- Pino: 水袋的body / 尻尾 / 泡と水
- Shushu: plush body / 耳 / 花 / 重い座位

“Animationを流用して色だけ変える”は禁止。
