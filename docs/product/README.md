# Product source use

The current product baseline is Grimo: a smartphone-first, local-first task management PWA with Tasks, Calendar, Grimo, and a planned Collection surface.

The authoritative character production direction is Full 3D → Blender → GLB/glTF → PlayCanvas. The four canonical identity images under `assets/grimo/source/<character>/<character>-Identity-canonical.png` are the current visual identity authority. The current app icon is also immutable.

The former `source-pack/` was created for the obsolete 2D/2.5D implementation path. It is preserved for historical research under `docs/archive/obsolete-2_5d/source-pack/`; archive material must not be treated as current architecture or production guidance.

For data and security boundaries, read `../decisions.md`, `../architecture/`, and `../setup/` first. Do not import archived UI, runtime, reward, or character-production assumptions into active work.
